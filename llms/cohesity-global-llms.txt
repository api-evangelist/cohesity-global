# Cohesity Global

> Cohesity is an AI-powered data security and management platform that consolidates backup and recovery, cyber resilience, threat defense, and data insights across cloud, on-premises, and SaaS environments. It exposes RESTful Helios and Cluster APIs plus first-party Python, Go, PowerShell, Ansible, and Terraform tooling for automating data protection against 1,000+ workloads.

## APIs

- [Cohesity Helios and Cluster REST API](https://developer.cohesity.com/): Data management, backup and recovery, cyber resilience, reporting, and site continuity operations. Base URL https://helios.cohesity.com/v2/.
